
# Lucas Justiniano - Personal Portfolio

## Overview

This portfolio website showcases my education,
technical skills, certifications, and programming
projects. It was created as part of my coursework
at ECPI University.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- JSON
- Web Storage API
- Git and GitHub
- GitHub Pages

## Project Features

- Responsive webpage design
- About Me and Technical Skills sections
- Dynamically generated project cards
- JavaScript objects and arrays
- Dynamic technical skills list using loops
- JSON.stringify() for data serialization
- JSON.parse() for data retrieval
- sessionStorage for project data
- localStorage for dark mode preferences
- Interactive navigation
- Welcome popup
- Contact form demonstration

## Dependencies

No external JavaScript libraries are required.

Project images use placeholder images from
placehold.co, which require an internet connection.

## How to Run

1. Open the GitHub Pages website.
2. Navigate through the portfolio sections.
3. View projects and their GitHub repositories.
4. Toggle dark mode as desired.
5. Refresh the page to verify project data loads
   from sessionStorage.
